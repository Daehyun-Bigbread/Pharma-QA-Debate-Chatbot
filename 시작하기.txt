  Pharma QA Debate Chatbot - 빠른 시작 가이드
===============================================================

🎯 초보자를 위한 3단계 실행 방법

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 1단계: OpenAI API 키 준비

1. 웹사이트 접속: https://platform.openai.com/api-keys
2. 회원가입 또는 로그인
3. "Create new secret key" 버튼 클릭
4. 생성된 키 복사 (sk-proj-로 시작하는 긴 문자열)
5. 결제 정보 등록 ($5 정도 충전 권장)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 2단계: 프로그램 실행

┌─ Windows 사용자 ────────────────────────────────┐
│                                                   │
│  "start.bat" 파일을 더블클릭하면 끝!             │
│                                                   │
│  또는 명령 프롬프트에서:                          │
│  > start.bat                                      │
│                                                   │
└───────────────────────────────────────────────────┘

┌─ Mac/Linux 사용자 ──────────────────────────────┐
│                                                   │
│  터미널을 열고:                                   │
│  $ python start.py                                │
│                                                   │
└───────────────────────────────────────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✨ 3단계: 자동으로 실행됩니다!

✅ 필요한 프로그램 자동 설치 확인
✅ 백엔드 서버 자동 시작
✅ 프론트엔드 서버 자동 시작
✅ 브라우저 자동으로 열림
✅ 챗봇 화면 바로 표시!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💬 처음 실행 시 API 키 입력

프로그램 실행 시 API 키 입력을 요청받으면:
1. 위에서 복사한 키를 붙여넣기
2. Enter 키 누르기
3. 자동으로 저장됨!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎮 사용 방법

1. 브라우저에 챗봇 화면이 열림
2. 토론 주제 입력 (예: "재밸리데이션 3 batch가 필수인가?")
3. Agent A, B의 성향 설정 (기본값 제공)
4. "토론 시작하기" 버튼 클릭
5. AI가 자동으로 토론 생성 (1-3분 소요)
6. 토론 결과 확인 및 요약 보기

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🛑 종료 방법

실행 중인 터미널 창에서:
- Windows: Ctrl + C
- Mac: Command + C 또는 Ctrl + C
